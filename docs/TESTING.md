# 验证清单

## 自动化

1. `cargo fmt --all -- --check`
2. `cargo test --workspace`
3. `cargo check --workspace --all-targets`
4. `cargo run -p mc-feedback-viewer -- --mcp` 后执行 MCP `initialize`、`tools/list` 和三个工具调用。
5. 检查 `tools/list` 只能看到 `get_account_status`、`list_player_comments`、`list_player_feedback`，且三者的 `readOnlyHint` 都为 `true`。
6. 登录响应的 `ret` 同时用 JSON 数字和数字字符串运行反序列化回归测试，防止网易接口类型漂移再次中断登录。
7. `node --check web-server/static/app.js` 检查原生前端语法。
8. `python -m py_compile deploy/web/deploy.py` 检查部署工具语法。

## Web 工作台

- 管理员：错误密码、登录限流、Secure/HttpOnly/SameSite Cookie、空闲过期、退出清除。
- CSRF：所有 POST/PUT/DELETE 在缺少或错误令牌时返回 403。
- 模型：保存后分别验证普通文本与 function calling；拒绝 HTTP、localhost、内网 IP、DNS 解析到内网以及重定向。连接超时、连接重置及 408/502/503/504 按 1–30 秒指数退避持续重连；401、403、429 和参数错误不重试。
- AI 查询：SSE 状态、停止、只读工具摘要、对话历史、大数据二次确认、全量分批和递归合并；整次对话不设时长、模型轮次或工具次数上限。摘要批次连续超时时必须压缩无关字段并二分后继续，禁止原样无限重放同一批数据；递归合并的每一层必须严格减少摘要数量，即使单项超过软字符上限也不得形成不收敛的单项分组。SSE 断线后可查询运行中的、成功或失败状态，错误必须脱敏写入服务日志；数据摘要已经完成而最终整理失败时，保留站内恢复结果，并按原请求生成 Markdown 恢复文件。
- 文件：CSV 以 UTF-8 BOM 开头，DOCX 是有效 ZIP，Markdown 有标题；未登录下载、路径穿越和过期文件均被拒绝。
- AI 工作：每天/每周/每月/Cron 未来五次预览，手动执行、重叠跳过、重启中断恢复、最近一次补跑、固定收件地址和单次最多一封；单次执行不设总时长上限。
- 响应式：桌面双栏与手机单栏均覆盖 AI 查询、工作、记录、文件和设置。
- 保留期：生成文件 30 天，聊天、数据集条件和运行正文 90 天，清理后磁盘文件与元数据一致。

服务器上线使用 `deploy/web/deploy.py --stage` 在 15678 暂存端口完成模型、网易真实只读工具与 Word 下载冒烟；全部通过后才允许 `--cutover`。切换失败会自动恢复旧服务和 nginx 配置。

## 桌面端人工测试

- 无已保存会话：启动后进入登录页。
- 错误密码：显示可理解错误，密码输入框被清空，不产生包含密码的日志。
- 安全验证：展开 Cookie 回退入口。
- 云服务器返回网易安全验证：网页生成一次性连接码；桌面端本机登录后完成连接；普通用户状态有效且管理员会话、绑定和评论数据不变；连接码不可重复使用并在 10 分钟后失效。
- 无效 Cookie：保持未登录状态，不覆盖已有有效会话。
- 有效登录：进入评论页，重启后能从系统钥匙串恢复。
- 评论：首次加载、刷新、分页、关键词、标签、开始/结束日期和空数据状态。
- 反馈：首次加载、刷新、分页、关键词、七种类型、已回复/未回复和空数据状态。
- 详情：长文本、中文、换行、特殊字符、冲突 JSON、坏图片、多个图片、已有回复和日志入口。
- 响应式：大于 920px、720–920px、小于 720px 三种宽度；窄屏详情可返回列表。
- 退出登录：界面回到登录页；MCP 随后返回 `missing`。

## 故障场景

- `no_login`：清除失效会话并要求重新登录。
- 403/429：显示限流错误，不清除会话。
- 连接超时、502、503、504：只重试一次，失败后保留会话。
- 返回未知字段：正常忽略；缺少必要数据时显示远端数据错误。
- Linux Secret Service 不可用：允许当前进程继续使用，但明确提示没有持久化且 MCP 无法复用。

## 真实账号只读冒烟

真实账号由使用者在本机输入。验证期间只允许账号状态、评论列表和反馈列表 GET 请求；通过抓包或服务端日志确认没有 `/reply`、`add_feedback` 或其他写入请求。
